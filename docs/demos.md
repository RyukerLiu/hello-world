# Demos

Each demo folder includes:
- `README.md` with goals and steps
- `prompt.md` with example user input
- `expected.md` with expected outcomes

## 01-cli-tool
Focus: Build a small CLI that processes input and includes tests.

## 02-web-ui
Focus: Generate a minimal UI with simple styling and component structure.

## 03-data-pipeline
Focus: Perform a simple data transformation with validation checks.

## 04-refactor
Focus: Refactor a messy script into clean, tested functions.
